# 💾 4×1 RAM — Verilog RTL Design

 ###📘 Overview
A simple 4×1 Random Access Memory (RAM) implemented in Verilog HDL.  
The design supports **synchronous write** and **asynchronous read** operations.

---

### Features
- 4 memory locations, 1-bit each  
- **Synchronous write**, **asynchronous read**  
- Compact RTL design, fully synthesizable  
- Verified using simulation  
- Analyzed for **area** and **timing** using Cadence Genus  
- Suitable for **ASIC or FPGA** integration  
- Clean and modular Verilog code  

---

### 🧰 Tools Used
- Verilog HDL  
- Icarus Verilog (Simulation)  
- Cadence Genus (Synthesis)

  - RTL Code
  - Ouput
  - Area and Time report
